# HDF5 Plotting App

This repository contains a small Streamlit application for visualising data stored in HDF5 files.

## Setup

1. Clone or copy the files in this repository into a directory on your machine.
2. Ensure Python 3.8+ is installed.
3. Install the dependencies using pip:

```bash
pip install -r requirements.txt
```

## Running the app

Launch the Streamlit application with:

```bash
streamlit run app.py
```

For convenience Windows users can also double‑click `Hdf5plot.bat` which executes the same command.

Uploaded HDF5 files and saved sessions are written to the `sessions/` folder.
